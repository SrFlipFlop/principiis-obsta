# Independent evaluator-agent stage (#7)

The operator runs this stage with `principiis evaluate --run <name> --ai-review (--step <id> | --final) --config EVALUATOR_JSON --prompt PROMPT_FILE --prompt-version VERSION`; it calls `principiis.investigation.investigate`. The stage never calls the writer or changes primary scoring. The primary file is referenced and hashed, never opened for writing. New oracle versions require explicit restricted evaluations and consistent rescoring; supplemental findings are not oracle revisions.

The evaluator configuration has `version`, `model`, `settings`, `runtime_config` (a separately authenticated isolated reviewer runtime, see [development runtime](DEVELOPMENT_RUNTIME.md)), `timeout_seconds: null` and `evidence: {}`. Host `agent` argv, `codex_config` and executable proof commands were removed in #67 and are rejected before any output is created. The reviewer receives the prompt in a disposable copy of the checkpoint inside the runtime. Raw redacted Codex JSONL stays in `agent.stdout`; the final agent message is saved as `agent.final.txt` and must be a JSON object with a `claims` array, each claim with nonempty `id` and `root_cause`. All claims are retained as `unresolved` until restricted proof support is reviewed. No development context includes this config, prompt, agent response, tools, findings or evaluator notes.

`investigation.json` records the primary reference/hash, configuration/prompt hashes and versions, agent exit/error status, supplemental claims, reported token usage and evaluation-only elapsed time. Config/prompt are retained verbatim, so supply no secrets. Resources scope is `independent_evaluation`; hosted-model memory remains unknown rather than zero. Failures retain partial logs and `evaluator_error`; a recorded evaluator failure can exit zero, so inspect the artifact status. Existing output directories are rejected.

Validation: `python3 -m unittest discover -s tests -p test_investigation_cli.py -v` uses a fake Docker client; no live agent, paid execution or pilot runs.
