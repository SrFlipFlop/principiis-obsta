# Expense request authoring self-review — 2026-11-15

Scope: public Tally requests authored from the approved baseline specification and the portal/support review lessons. This is an author self-review, not an independent review or oracle qualification.

| Prior mistake | Applied choice |
| --- | --- |
| Defensive recipes in ordinary requests | Product features and business roles only; no exploit cases or secure implementation prescriptions |
| Retroactive response assumptions | Arrays, summary/detail fields and integer-cent semantics established in request 1 |
| Ambiguous list/search scope | Personal ledger default; explicit team selection; literal substring matching introduced with search |
| Unclear departure and creator rights | Team removal ends team access; handover transfers unfinished responsibility and preserves historical authors |
| Undefined totals and transfer counts | Integer cents; explicit report/filter set; exact definitions for both departure counts |
| Regression laundering | Preauthored ordinary finance/receipt examples; no run-derived findings; correct implementations can retain behavior |
| Unnecessary refactor churn | Existing adequate boundaries may be retained with evidence |

Author checks cover cumulative statuses, submitted reassignment after reviewer departure, returned corrections, owner transfer, receipt persistence and original creator attribution. The departure feature explicitly clears self-assigned or departed reviewer assignments while retaining submitted claims for owner reassignment. Counts can overlap and are defined per distinct expense.

No benchmark agent has developed the app. Owner review, hidden expectation/property mappings, browser/backend checks, alternative-valid controls and runtime qualification remain outstanding. Hash checks identify authored bytes only.

The parent agent separately reviewed all ten requests before publication. It checked cumulative draft/returned/submitted/final behavior, removal versus transferred responsibility, reassignment after reviewer departure or self-assignment, report/budget status semantics, response shapes, and maintenance/regression framing. No blocking public-contract contradiction was identified. This textual review is not executable oracle qualification.
