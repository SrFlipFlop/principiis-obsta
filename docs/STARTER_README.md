# Principiis Obsta

**Resist at the beginning.** An empirical research project on preventing security vulnerabilities during AI-assisted software development—not only detecting them in CI/CD or production.

> Status: **research bootstrap, not an implemented benchmark**. The charter and methodology are working proposals. The researcher owns the final objectives and experimental design.

## Research question

Which security interventions delivered to coding agents—generic and targeted secure-coding knowledge, explicit security requirements, threat-aware specifications, and local review/repair loops—improve *secure-and-functional* software generation, at what cost, and for which agents/models?

The aim is to publish reproducible experiments, a public repository, and a technical write-up or paper. Negative results are valuable. This is not intended to be a commercial scanner or a replacement for independent AppSec controls.
