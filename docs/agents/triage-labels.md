# Triage labels

| Role | GitHub label |
| --- | --- |
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for autonomous implementation | `ready-for-agent` |
| Requires human work | `ready-for-human` |
| Will not be actioned | `wontfix` |

Names are owner-approved. On 2026-11-14, publication created and verified `ready-for-agent` and `ready-for-human`; `wontfix` already existed. `needs-triage` and `needs-info` were not created. Check their existence before use. Readiness labels do not override an issue's blockers.
