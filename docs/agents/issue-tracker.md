# Issue tracker — GitHub

Work items and new PRDs live in GitHub Issues for `SrFlipFlop/principiis-obsta`. Scope is in [PROJECT.md](../../PROJECT.md); the [archived issue breakdown](../archive/planning/BASELINE_ISSUE_BREAKDOWN.md) records the original publication, not live status. Read the current issue body, comments and blockers before starting work.

Use `gh` from this checkout. Read tickets with `gh issue view <number> --comments`; list with `gh issue list`. If this installed `gh` fails on the deprecated Projects query, use `gh issue view <number> --json number,title,body,state,comments`. Create issues, PRs or comments only when the owner asked for it in the session. For multiline bodies write a temporary UTF-8 file and pass `--body-file`; preserve exact text. Keep hidden evaluator material and confidential data out of tickets.
