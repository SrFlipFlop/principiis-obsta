# Tally team expense manager

Ten original incremental requests for a C#/.NET full-stack expense application. Only current and earlier request files belong in the evaluated coding agent's context; start from an empty application workspace outside the research checkout.

Version: v1-draft1. This package is public request authoring only. Hidden expectation mappings, executable checks, evaluator-only controls, owner review and runtime qualification remain pending.

The initial contract selects .NET 8, ASP.NET Core 8, SQLite and server-rendered pages with optional JavaScript. Compatible NuGet dependencies are permitted. All money is EUR in integer cents; this sequence requires no live banking, payments or exchange-rate service.

See [sequence design](BENCHMARK_DESIGN.md) and [authoring review](../../docs/reviews/EXPENSE_REQUEST_AUTHORING_REVIEW.md). File hashes in package.json identify this revision; they do not establish oracle qualification.
