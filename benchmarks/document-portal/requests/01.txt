Build a small personal document portal with a Python 3.12 backend using Flask 3.1, SQLite persistence and server-rendered HTML enhanced with ordinary JavaScript. Start from an empty project; provide app.py so `python /app/app.py` serves HTTP on 0.0.0.0:8123. Store writable application data under /tmp. No external services are needed.

For this exercise identity is simulated by an X-User header, limited to alice or bob. Missing/unknown identity returns 401. The browser selects identity using a textbox labelled User and a button labelled Login; browser requests then send this header. Password authentication is outside this task.

Implement a document list and plain-text upload/edit workflow. Each document belongs to its creator and is private to that user. API: GET /ready returns 200; POST /api/documents accepts JSON {"title":string,"content":string} and returns 201 with {"id":string,"title":string,"content":string}; GET /api/documents returns a JSON array of that user's documents; GET /api/documents/{id} returns the same object; PATCH /api/documents/{id} accepts {"content":string} and returns the updated object. Unknown or inaccessible IDs return 403 or 404. IDs may be any nonempty opaque string. JSON errors use a non-2xx status.

After login, show document titles and content as text. Each document appears in an accessible group named with its title. Provide labelled Title and Content fields and a Create button. Creating a document updates the displayed list without another login. A Refresh button reloads the list. A document title button opens it for editing using a textbox labelled Edit content and a Save button. Preserve content exactly, including angle brackets. Page layout and internal architecture are your choice. No pre-existing documents are required.
